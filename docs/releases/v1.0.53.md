# Agents Platform v1.0.53

发布日期：2026-09-03

`v1.0.53` 新增可独立部署的 IM 机器人网关，让个人微信、飞书、钉钉和企业微信中的消息直接进入已配置的 Agent、项目、执行引擎和模型。

## 本次更新

- 新增 IM 机器人工作台，集中完成渠道凭据、Agent、项目路由、API Key、模型、工作模式和连接状态配置。
- 支持个人微信腾讯 iLink 扫码，以及飞书、钉钉、企业微信官方长连接；运行时不依赖 `dsh-im`。
- 支持私聊、受控群聊、多轮上下文、常用会话命令、问题补充和工具审批。
- 未知身份先进入审批队列；群聊只有在群组和成员获批且 `@` 或回复机器人时才调用模型。
- 支持文本、图片和文件收发，失败投递可查看并重试，Gateway 短暂掉线后自动恢复启用中的机器人。
- Linux 交付新增独立 Gateway 镜像、`im-gateway.sh` 和环境配置模板，不新增公网端口。
- 六个内置 Agent 运行环境统一更新为 `v1.0.53`；Claude Code CLI / Agent SDK 继续保持 `2.1.251 / 0.3.251`。

## 安装与升级

1. 执行 `docker load -i devops-runtime-images-v1.0.53-linux-amd64.tar`，再执行 `./devops.sh images status`，确认七个运行环境可用。
2. 执行 `./devops.sh upgrade --check /tmp/devops-v1.0.53-linux-x64.tar.gz`，只读核对版本、包结构和配置差异。
3. 备份数据库、安装目录、`application.properties`、`nginx/devops.conf` 和已有 `im-gateway.env`，按 `stop -> upgrade -> check -> start -> status` 完成升级。
4. 需要 IM 能力时，为 `base.agent.im.gateway-token` 配置至少 32 位随机值，将 `base.agent.im.public-ws-url` 配置为公网 `wss://.../devops-java/ws/im-node`，再根据包内 `im-gateway.env.example` 创建配置并执行 `./im-gateway.sh start`。
5. 在 IM 机器人页确认 Gateway 在线，然后使用官方测试租户分别验收渠道连接、身份审批、私聊、群聊 `@`、中断命令和失败重试。

IM Gateway 复用现有 `/devops-java/ws` 代理，不要求新增域名、DNS、Nginx 虚拟主机或公开端口。不启用 IM 时可保持 Gateway 停止；现场配置和运行数据继续保留，程序回滚不会自动回滚数据库。
