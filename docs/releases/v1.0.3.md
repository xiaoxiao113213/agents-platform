# Agents Platform v1.0.3

发布日期：2026-08-09

`v1.0.3` 完善了内置 Agent 的能力配置、项目规则和交付验证，并让 Grafana 多数据源大盘能够在平台中直接配置和使用。

## 本次更新

- 一套 Grafana 配置可绑定 1 至 20 套数据源组合。每个 Grafana 数据源 UID 对应一套 MySQL 只读连接，同一 Dashboard 的不同组件可分别选择不同数据源，也可以复用同一数据源。
- Grafana Agent 会先探查真实数据库结构、校验数据源绑定与只读 SQL，再创建或更新 Dashboard；交付后回读组件使用的数据源与查询结果。
- 内置 Agent 按工作类型稳定初始化规则、Skill、能力配置和项目模板，并在交付前增加自我验证阶段。
- Agent 项目网站可从常见构建目录和项目子目录稳定定位发布内容，并返回可直接访问的入口。
- 问答、执行确认和文件工作台的信息层级更清晰，长内容、授权范围和操作结果更容易阅读。
- 创建 Agent 时可继续选择多个 API Key；普通用户的文件列表不会显示平台内部配置文件。
- 修复了已知问题。

## 安装与升级

- 新客户可以使用本版本在 Linux x64 环境中连接空的 MySQL 8 数据库完成全新安装。
- `v0.0.1` 及后续正式版本都可以直接累计升级到 `v1.0.3`，无需补装中间版本；升级前可先使用安装包中的只读检查命令确认环境和配置差异。
- 升级不会自动覆盖现场 `application.properties`、Nginx 配置、运行数据和日志。
- 跨较大版本升级前，请在数据库备份副本上核对业务数据，并备份数据库、安装目录和实际配置文件。
- 程序回滚不会自动回滚数据库，恢复旧程序前必须确认数据库兼容或同时恢复升级前备份。

生产环境要求 Linux x64、Java 21+、MySQL 8 与 Docker。详细步骤请参阅官网部署指南和安装包内说明。
