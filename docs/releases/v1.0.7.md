# Agents Platform v1.0.7

发布日期：2026-08-10

`v1.0.7` 带来更细致的功能权限、更自然的项目切换，以及更稳定的长内容与任务消息展示。

## 本次更新

- 模型连接管理和 Issue 管理都可以通过角色权限分配，不再受固定账号限制，团队职责划分更灵活。
- Issue 权限细分为查看、项目管理、创建、编辑、评论、流转、删除和项目令牌，项目访问范围仍可独立授权。
- Agent 正在执行任务时也可以切换项目；原任务会继续完成，当前页面只展示所选项目的会话、消息和运行状态。
- 切回原项目后可以继续查看并处理原任务中的问答，不会因为浏览其他项目而中断执行。
- Task、子任务和超长内容的展示更加紧凑稳定，小尺寸窗口和分栏模式下不再挤压对话区域，并修复了已知问题。

## 安装与升级

- 新客户可以使用本版本在 Linux x64 环境中连接空的 MySQL 8 数据库完成全新安装。
- `v0.0.1` 及后续正式版本都可以直接累计升级到 `v1.0.7`，无需补装中间版本；升级前可先使用只读检查命令确认环境和配置差异。
- 已安装客户可以先独立更新启动器，再使用 `./devops.sh update` 在线升级；运行环境也可以通过独立命令提前下载。
- 升级不会自动覆盖现场 `application.properties`、Nginx 配置、运行数据和日志。
- 跨较大版本升级前，请在数据库备份副本上核对业务数据，并备份数据库、安装目录和实际配置文件。
- 程序回滚不会自动回滚数据库，恢复旧程序前必须确认数据库兼容或同时恢复升级前备份。

生产环境要求 Linux x64、Java 21+、MySQL 8 与 Docker。详细步骤请参阅官网部署指南和安装包内说明。
