# Agents Platform v1.0.14

发布日期：2026-08-14

`v1.0.14` 重点提升 Agent 在长期对话、系统重启和项目服务恢复场景下的稳定性，并继续完善离线安装体验。

## 本次更新

- 平台或 Agent 重启后会主动恢复原来要求运行的项目服务，不需要先进入服务面板或手工刷新。
- 项目服务恢复过程增加并发保护和失败隔离，单个项目服务异常不会影响整个 Agent 继续工作。
- Agent 对话页的后台刷新保持当前项目、消息和滚动状态，减少整页闪动与无关区域重复刷新。
- 审核面板关闭后不再持续执行无意义的高频刷新，长时间对话更加稳定。
- 历史会话暂时无法恢复时会保留原会话并明确提示，不会静默切换到缺少上下文的新会话。
- 离线 JDK、Maven 和 pnpm 安装兼容非交互环境，继续直接复用服务器缓存，减少重复下载和等待。
- Linux 终端输入、新会话创建、服务入口自动出现和终端角色权限等能力继续保持可用。
- 修复了已知问题。

## 安装与升级

- 新客户可以使用本版本在 Linux x64 环境中连接空的 MySQL 8 数据库完成全新安装。
- `v0.0.1` 及后续正式版本都可以直接累计升级到 `v1.0.14`，无需补装中间版本；升级前可先使用只读检查命令确认环境和配置差异。
- 已安装客户先获取 `devops-runtime-images-v1.0.14-linux-amd64.tar` 并执行 `docker load -i devops-runtime-images-v1.0.14-linux-amd64.tar`，确认导入成功后再执行 `./devops.sh update`。
- 需要为 Agent 安装 JDK、Maven 或 pnpm 时，将 `devops-runtime-software-v1.0.14-linux-amd64.tar.gz` 一次解压到 `/opt/devops/devops/runtime-software-cache`；平台会自动校验并复用。
- 本版本没有新增生产配置项，也没有新增域名、DNS、Nginx、证书或端口要求。
- 升级不会自动覆盖现场 `application.properties`、Nginx 配置、项目工作区、会话、Skill、MCP、运行数据和日志。
- 程序回滚不会自动回滚数据库，升级前请备份数据库、安装目录和实际配置文件。

生产环境要求 Linux x64、Java 21+、MySQL 8 与 Docker。详细步骤请参阅官网部署指南和安装包内说明。
