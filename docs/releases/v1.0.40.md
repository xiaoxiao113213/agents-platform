# Agents Platform v1.0.40

发布日期：2026-08-26

`v1.0.40` 重点改善长任务的状态可见性。任务内容充分使用对话空间，运行状态在会话列表、任务面板和加载反馈之间保持一致，减少任务仍在执行却看起来已经停止的误判。

## 主要变化

- 对话 Task 面板使用正文栏全部可用宽度，长任务步骤和结果更容易阅读。
- 运行中的会话持续显示明确状态，切换项目或会话后仍能正确反映后台任务进度。
- 加载圆弧保持连续动态反馈，用户可以更直观地判断 Agent 是否仍在工作。
- 本版本不新增域名、DNS、证书、Nginx 站点、公开端口、外部服务或生产配置键。

## 安装与升级

- 生产环境继续要求 Linux x64、Java 21+、MySQL 8 和 Docker Engine。
- 全新安装可在新目录解压主程序包并运行 `./devops.sh install`，使用空的 `devops` 数据库完成初始化。
- 既有环境支持从 `v1.0.39`、`v0.0.1` 及其后的正式版本直接累计升级，无需补装中间版本。
- 升级前先备份数据库、安装目录与现场配置，并准备与主程序同版本的运行环境包。

## 升级步骤

1. 执行 `docker load -i devops-runtime-images-v1.0.40-linux-amd64.tar`，再执行 `./devops.sh images status`，确认所有运行环境均可用。
2. 执行 `./devops.sh update --check` 或 `./devops.sh upgrade --check /tmp/devops-v1.0.40-linux-x64.tar.gz`，只读核对版本、包结构和现场配置差异。
3. 完成备份后按 `./devops.sh stop`、`./devops.sh upgrade /tmp/devops-v1.0.40-linux-x64.tar.gz`、`./devops.sh check`、`./devops.sh start`、`./devops.sh status` 的顺序完成升级。
4. 登录平台发起一次长任务，确认 Task 面板占满正文栏、加载动画持续运行，并检查左侧当前会话在任务结束前保持运行状态。

同版本和降级仍会被拒绝。程序目录回滚不会自动还原业务数据库，生产升级前必须保留可恢复的数据库备份。
