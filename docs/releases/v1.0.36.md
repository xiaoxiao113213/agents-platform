# Agents Platform v1.0.36

## 版本概览

`v1.0.36` 让 Agent 项目、Skill、MCP、文件预览和协作空间形成更完整的一体化工作流。进入 Agent 后优先回到已有项目，项目需要的能力可以直接查找、预览和安装，协作空间也具备清晰的成员授权与操作记录。

## 主要更新

- 进入 Agent 工作区时默认打开第一个可访问项目；尚无项目时先创建项目，再开始对话和配置能力。
- Skill 与 MCP 使用独立列表展示。MCP 页面聚焦平台内置能力，Skill 对全部已登录成员共享，并显示真实的 Agent 与项目使用情况。
- 项目内可反查已经添加的 Skill，搜索、选择、安装和移除使用同一套项目范围。
- 工作区只展示项目内相对路径，工具栏保留产物、应用、Skill、文件等主要入口，其余工具以紧凑图标呈现并提供说明。
- Skill 文档会区分能力元信息和正文；工作区与对话文件支持 Markdown、代码、HTML、图片、PDF、音频和视频预览。
- 协作空间支持管理员按成员授权和撤销；分享 Agent 时，接收者会按分享的项目范围自动获得相关协作空间访问权。
- 授权记录会保留来源、操作者、成员、Agent、项目和原因，方便管理员审计权限变化。
- 协作空间提供外部 Agent 接入指引，便于其他电脑上的 Agent 使用同一套事项与资料能力。
- 领域主题可维护平台名称，并在登录、导航和业务界面统一生效；个人主 Agent 的名称更容易识别。
- 修复了工具栏遮挡、图标缺失与抖动、Skill 预览、产物数字遮挡和当前会话首轮完成误弹通知等已知问题。
- 修复 Windows 远程 Agent 创建单端点托管应用时可能误判端口未监听的问题。

## 安装与升级

### 前置条件

- 继续使用 Linux x64、Java 21+、MySQL 8、Docker 和独立 Nginx。
- 升级前备份数据库、安装目录、`application.properties` 和 `nginx/devops.conf`。
- 确认磁盘空间足够保存并导入 6 个运行环境；运行环境包和主程序包必须同为 `v1.0.36`。
- 本版本没有新增域名、DNS、证书、公开端口或生产配置键，继续保留现场已有配置。

### 升级步骤

1. 执行 `docker load -i devops-runtime-images-v1.0.36-linux-amd64.tar`，再执行 `./devops.sh images status`，确认 6 个运行环境均可用。
2. 必要时先运行 `curl -fsSL https://mmmqaz.cn/releases/update-launcher.sh | bash`，并确认 `./devops.sh launcher-version` 不低于 `15`。
3. 执行 `./devops.sh upgrade --check /tmp/devops-v1.0.36-linux-x64.tar.gz`，确认版本、包结构和现场配置差异。
4. 完成备份后执行 `./devops.sh stop`、`./devops.sh upgrade /tmp/devops-v1.0.36-linux-x64.tar.gz`、`./devops.sh check`、`./devops.sh start` 和 `./devops.sh status`。
5. 不要覆盖现场 `application.properties` 或 `nginx/devops.conf`。

### 产品内验收

1. 登录平台并进入一个已有 Agent，确认默认打开第一个可访问项目；没有项目的 Agent 应先显示完整的新建项目流程。
2. 打开 Skill 和 MCP 列表，确认可搜索平台能力、查看真实使用情况，并能在项目中反查已安装 Skill。
3. 在工作区分别预览一个 Markdown、HTML、图片或 PDF 文件，确认路径显示为项目内相对路径。
4. 在协作空间中授权一名成员，再通过 Agent 分享授予另一名成员，确认两种来源和撤销记录都能在授权日志中区分。
5. 切换一个已配置领域主题，确认平台名称、Logo、背景和按钮等主题信息在登录及业务页面生效。

### 常见问题

- 升级后找不到协作空间：确认当前用户有管理员手工授权，或收到的 Agent 分享范围包含已绑定该空间的项目。
- 撤销 Agent 分享后仍可访问：该成员可能还保留管理员手工授权或其他 Agent 分享来源，请在授权日志中核对。
- HTML 或媒体文件预览不完整：浏览器沙箱、跨域策略或本机编解码器可能限制部分内容，可下载后在受信任环境打开。
- 升级预检提示配置差异：保留现场文件，以包内 `.example` 为参考逐项合并。

### 全新安装

全新安装执行 `./devops.sh install`。安装完成后登录平台，先确认领域主题和平台名称，再创建或选择 Agent 项目并配置所需 Skill、MCP 与协作空间。

同版本与降级仍会被拒绝。程序回滚不会自动回滚数据库，升级和回滚都不会覆盖现场配置、项目工作区、文件与运行数据。
