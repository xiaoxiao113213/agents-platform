# Agents Platform v1.0.29

## 版本概览

`v1.0.29` 重点改善 Agent 工作区文件的可见性和管理体验。大型依赖目录不会再挤占文件列表，用户可以按项目维护忽略规则，Windows 与 Linux 项目的交付文件也能用一致方式识别和下载。

## 主要更新

- 工作区默认忽略常见语言、框架的依赖目录、缓存和构建中间文件，让真实源码与交付文件优先显示。
- 默认规则按类别清晰展示，可逐项停用并随时恢复，适合需要检查依赖或缓存内容的排障场景。
- 支持新增、修改、删除项目自己的忽略目录，也可以直接在目录行执行快捷忽略。
- 文件树和搜索使用相同规则，配置保存后立即生效，避免目录中不可见但搜索仍出现的差异。
- `deliverables`、`artifacts`、`output` 等常见交付目录默认保留，不会被通用规则误隐藏。
- Windows 与 Linux 项目中的产物路径按当前项目边界统一识别，减少文件实际存在但产物固化失败的情况。
- 自定义路径会拒绝绝对路径、跨目录写法和重复项，避免误忽略其它项目内容。
- 本版本不新增域名、DNS、Nginx、证书、公开端口或外部服务配置要求。
- JDK、Maven、pnpm 软件内容没有变化，继续复用 `v1.0.15` 软件离线包和服务器缓存。
- 修复了已知问题。

## 升级说明

1. 升级前备份数据库、安装目录、`application.properties` 和 `nginx/devops.conf`。
2. 执行 `docker load -i devops-runtime-images-v1.0.29-linux-amd64.tar` 导入本版本运行环境。
3. 执行 `./devops.sh upgrade --check /tmp/devops-v1.0.29-linux-x64.tar.gz`，确认版本、配置差异和包结构。
4. 完成累计升级后运行 `./devops.sh check`，启动服务并等待 Agent 重新连接。
5. 打开一个包含常见依赖目录的 Agent 项目，确认源码和交付目录可见，依赖目录默认隐藏。
6. 在工作区设置中停用并恢复一项默认规则，确认文件树与搜索同步变化。
7. 新增、修改并删除一个自定义忽略目录，再通过目录行快捷忽略一次，确认配置均立即生效。
8. 在 Windows 或 Linux Agent 中生成一个文件型产物并从平台下载，确认历史产物可用。
9. 本版本没有新增平台 Nginx 参数；执行 `nginx -t` 后再重载现场配置。
10. 需要离线安装 JDK、Maven 或 pnpm 时继续使用 `devops-runtime-software-v1.0.15-linux-amd64.tar.gz`。

同版本与降级仍会被拒绝。程序回滚不会自动回滚数据库，升级前必须保留可恢复备份。
