# Agents Platform v1.0.51

发布日期：2026-09-02

`v1.0.51` 将 SDK 完整案例扩展到六套，并把 SDK 开发入口、角色权限和共享项目环境配置整理为一致的交付能力。

## 本次更新

- 开发者中心新增“Agent 工程工作台”和“策展引航员”两个完整案例，与已有四套案例一起支持下载、说明预览、文件树浏览和源码搜索。
- Agent 工程工作台采用 Node.js + React + H2，覆盖项目、任务、产物和 Agent 对话；策展引航员采用 Spring Boot + React + H2，覆盖策展、评阅、线上展览、观众反馈和 Agent 导览。
- 六套案例均纳入统一构建与交付校验。基于案例继续开发时，应先复制到 Agent 项目的独立业务目录，后续平台更新不会覆盖客户工程。
- Agent 工作区中的 SDK 与终端改为纯图标入口，SDK 位于终端左侧，并随工具栏一起展开或收起；窄屏下仍保留完整入口。
- 角色管理新增独立“Agent SDK”权限，可分别控制 SDK 项目能力；页面和服务端使用同一权限边界。
- 共享项目成员可以维护当前可访问 Agent 的环境变量，便于完成项目运行配置；API Key 绑定和终端权限没有放宽。
- 六个内置 Agent 运行环境统一更新为 `v1.0.51`。

## 安装与升级

1. 执行 `docker load -i devops-runtime-images-v1.0.51-linux-amd64.tar`，再执行 `./devops.sh images status`，确认六个运行环境可用。
2. 执行 `./devops.sh update --check` 或 `./devops.sh upgrade --check /tmp/devops-v1.0.51-linux-x64.tar.gz`，只读核对版本、包结构和配置差异。
3. 备份数据库、安装目录、`application.properties` 和 `nginx/devops.conf`，按 `stop -> upgrade -> check -> start -> status` 完成升级。
4. 打开开发者中心，确认六个完整案例均可查看和下载；复制任一案例到独立业务目录后完成平台配置和一次真实对话。
5. 在角色管理中按需授予“Agent SDK”，再由项目所有者和共享成员分别核对 SDK、环境变量、API Key 和终端边界。

本版本没有新增域名、DNS、证书、Nginx 虚拟主机、公开端口或外部服务要求。现场配置和运行数据继续保留；程序回滚不会自动回滚数据库。
