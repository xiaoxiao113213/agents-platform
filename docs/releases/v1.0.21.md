# Agents Platform v1.0.21

## 版本概览

`v1.0.21` 重点解决单个 Agent 重建后旧运行实例抢占连接的问题，并完善全局管理看板、工作区返回状态和内置工程 Skill，让对话、项目服务与日常运维更容易恢复和定位。

## 主要更新

- Docker Agent 会识别当前运行实例，重建后遗留实例不能再反复抢占控制连接或项目服务通道；其他 Agent 和远程节点不受影响。
- 运维看板展示每个 Agent 的当前实例、遗留实例和多实例异常。最高管理员确认后可精确清理遗留容器，并保护当前实例和其他 Agent。
- 全局看板将运维状态与用户数据分开查看；用户视图增加活跃、在线、资源密度、使用分层、趋势、搜索、筛选和排序。
- 从对话工作区返回管理台时会恢复原页签、用户筛选、搜索条件和远程在线状态，减少反复查找。
- 项目服务面板优化长文本和窄宽度布局，服务、端点、端口与状态更容易扫描。
- 内置 Spring Boot、Node.js 和 Python 工程 Skill 增加 SQLite 开发模式，以及切换到 MySQL 时的备份、迁移、校验和回滚步骤。
- JDK、Maven、pnpm 内容没有变化，继续复用 `v1.0.15` 软件离线包和服务器缓存。
- 修复了已知问题。

## 升级说明

1. 升级前备份数据库、安装目录、`application.properties` 和 `nginx/devops.conf`。
2. 执行 `docker load -i devops-runtime-images-v1.0.21-linux-amd64.tar` 导入本版本运行环境。
3. 执行 `./devops.sh upgrade --check /tmp/devops-v1.0.21-linux-x64.tar.gz`，确认版本、配置差异和包结构。
4. 完成累计升级后运行 `./devops.sh check`，启动服务并等待 Agent 重新连接和运行环境更新。
5. 在运维看板确认 Agent 只有一个当前实例；发现遗留实例时核对 Agent 和完整容器 ID，再由最高管理员清理。
6. 打开真实 Agent 对话和项目服务，验证连续消息、普通接口、上传、SSE 或 WebSocket，并确认状态与端口诊断一致。
7. 本版本没有新增 Nginx 参数，升级器会保留现场配置；执行 `nginx -t` 后再重载。
8. 需要离线安装 JDK、Maven 或 pnpm 时继续使用 `devops-runtime-software-v1.0.15-linux-amd64.tar.gz`。

同版本与降级仍会被拒绝。程序回滚不会自动回滚数据库，升级前必须保留可恢复备份。
