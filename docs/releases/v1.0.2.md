# Agents Platform v1.0.2

发布日期：2026-08-09

`v1.0.2` 进一步简化平台安装和 Agent 项目网站发布，让常用配置采用一致的默认规则，减少不必要的检查与重复填写。

## 本次更新

- Agent 项目网站自动使用平台当前域名和端口下的固定路径，无需重复填写公开访问地址。
- 项目网站发布目录跟随平台数据根目录，应用与 Nginx 默认配置保持一致。
- 安装和启动会直接复用本机已有运行环境，缺少的内容会在需要时自动下载。
- 部署检查兼容常见的 Nginx 配置写法，避免合法空白格式造成错误提示。
- 远程 Agent 地址仅在实际使用远程 Agent 时配置，不再影响普通安装检查。
- 项目网站发布成功后会直接返回可点击的访问入口。
- 修复了已知问题。

## 安装与升级

- 新客户可以使用本版本在 Linux x64 环境中连接空的 MySQL 8 数据库完成全新安装。
- `v1.0.0` 和 `v1.0.1` 用户都可以直接升级到 `v1.0.2`，无需补装中间版本；升级前可先使用安装包中的只读检查命令确认环境和配置差异。
- `v1.0.0` 是 v1 安装代际基点，`v0.x` 不支持原地升级到 `v1.x`。请使用新的安装目录和空数据库部署 v1 版本。
- 升级不会自动覆盖现场配置。正式操作前请备份数据库、安装目录和配置文件。

生产环境要求 Linux x64、Java 21+、MySQL 8 与 Docker。详细步骤请参阅官网部署指南和安装包内说明。
