# Agents Platform v1.0.50

发布日期：2026-09-01

`v1.0.50` 将 SDK 完整案例扩展到四套，统一了独立部署时的账号初始化方式，并完善了共享项目成员的工具使用边界。

## 本次更新

- 开发者中心新增“Agent 智能法律工作台”完整案例，与智能客服、Agent Console、Agent Observatory 一起支持下载、说明预览、文件树浏览和源码搜索。
- 四套案例首次启动都会自动创建 `admin` 管理员，初始密码为 `11111111`；修改密码后会持久保存，后续重启不会恢复初始密码。
- 案例登录后再配置平台 URL、SDK API Key、Agent、执行引擎、对应模型 Key 和模型，便于客户拿到独立部署包后完成初始化。
- 基于案例继续开发时，必须先把案例复制到 Agent 项目的独立业务目录；平台后续更新 SDK 和案例源码时不会覆盖客户工程。
- Agent 项目工具栏把“SDK 开发”固定放在“终端”左侧，避免在折叠工具中反复查找。
- 共享项目成员可以使用产物、应用、Skill、文件、协作空间、Workflow、MCP、项目规则、SDK 开发等项目工具；终端仍只对 Agent 所有者开放。
- 终端所有权校验同时在页面和服务端执行，不能通过直接连接绕过。
- 修复了已知问题。

## 安装与升级

1. 执行 `docker load -i devops-runtime-images-v1.0.50-linux-amd64.tar`，再执行 `./devops.sh images status`，确认六个运行环境可用。
2. 执行 `./devops.sh update --check` 或 `./devops.sh upgrade --check /tmp/devops-v1.0.50-linux-x64.tar.gz`，只读核对版本、包结构和配置差异。
3. 备份数据库、安装目录、`application.properties` 和 `nginx/devops.conf`，按 `stop -> upgrade -> check -> start -> status` 完成升级。
4. 打开开发者中心下载四个完整案例中的任意一个，复制到独立业务目录后完成登录、平台配置和一次真实对话。
5. 分别使用项目所有者和共享成员进入同一项目，确认共享成员可使用项目工具但看不到终端。

本版本没有新增域名、DNS、证书、Nginx 虚拟主机、公开端口或外部服务要求。现场配置和运行数据继续保留；程序回滚不会自动回滚数据库。
