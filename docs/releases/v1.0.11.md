# Agents Platform v1.0.11

发布日期：2026-08-13

`v1.0.11` 重点提升共享对话、页面刷新恢复和远程 Agent 项目能力的可靠性。多人可以更稳定地共用同一个 Agent 与会话，Windows 和 Linux 远程 Agent 也能按各自配置正确使用项目应用和内置能力。

## 本次更新

- 同一共享会话按顺序处理每轮输入，避免多人同时发送造成消息前后错乱。
- 消息发送后立即显示已接收和执行状态，快速重复点击不会产生两次相同请求。
- 新会话执行期间刷新页面会自动恢复真实会话、运行状态、工具过程和最终回复，不再出现临时会话残留。
- Windows 与 Linux 远程 Agent 会使用各自的平台身份和工作区配置，同一台机器运行多个 Agent 时也能保持相互独立。
- 项目应用支持常见端口变量写法；修改配置或人工重启后会重新进行健康检查，不再受之前失败记录影响。
- 项目应用可按项目开启公网访问，复制独立地址后可以直接分享；未开启时继续只允许项目成员访问。
- 项目中沉淀的 Skill 可以贡献到能力广场，贡献者也可以继续更新自己分享的 Skill。
- Skill ZIP 导入兼容单个 Markdown 文件和常见 macOS 压缩包元数据，导入失败时会显示明确原因。
- 新增独立运行环境交付包，可一次导入当前版本所需的全部运行环境。
- 修复了已知问题。

## 安装与升级

- 新客户可以使用本版本在 Linux x64 环境中连接空的 MySQL 8 数据库完成全新安装。
- `v0.0.1` 及后续正式版本都可以直接累计升级到 `v1.0.11`，无需补装中间版本；升级前可先使用只读检查命令确认环境和配置差异。
- 已安装客户先获取 `devops-runtime-images-v1.0.11-linux-amd64.tar` 并执行 `docker load -i devops-runtime-images-v1.0.11-linux-amd64.tar`，确认导入成功后再执行 `./devops.sh update`；升级过程会复用本地已有内容。
- 升级不会自动覆盖现场 `application.properties`、Nginx 配置、项目工作区、会话、Skill、MCP、运行数据和日志。
- 本版本没有新增生产配置项。使用项目应用独立地址时，仍需完成项目根域通配 DNS 与 Nginx 项目应用虚拟主机配置。
- 跨较大版本升级前，请在数据库备份副本上核对业务数据，并备份数据库、安装目录和实际配置文件。
- 程序回滚不会自动回滚数据库，恢复旧程序前必须确认数据库兼容或同时恢复升级前备份。

生产环境要求 Linux x64、Java 21+、MySQL 8 与 Docker。详细步骤请参阅官网部署指南和安装包内说明。
