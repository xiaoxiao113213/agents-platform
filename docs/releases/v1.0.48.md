# Agents Platform v1.0.48

发布日期：2026-08-31

`v1.0.48` 简化了新建会话的运行配置，并补齐两种执行引擎的定时任务能力。团队可以在工作区直接选择执行引擎、API Key 和模型，发送首条消息后由会话持续保留这套配置。

## 本次更新

- 新建空白对话直接显示执行引擎、API Key 和模型，无需进入 Agent 配置页反复切换。
- 切换执行引擎后自动展示该引擎绑定的 Key 和模型；未绑定 Key 的引擎会明确提示且不可选择。
- 首条消息发送后立即固定会话引擎，已有会话继续使用创建时保存的运行配置。
- 协作引擎和开发引擎会话都支持创建定时任务，并按原会话的引擎、Key、模型和工作模式继续执行。
- 修复长任务完成或共享会话恢复时同一条用户输入偶尔重复显示的问题。
- 六个内置 Agent 运行环境统一更新为 `v1.0.48`。

## 安装与升级

1. 执行 `docker load -i devops-runtime-images-v1.0.48-linux-amd64.tar`，再执行 `./devops.sh images status`，确认六个运行环境可用。
2. 执行 `./devops.sh update --check` 或 `./devops.sh upgrade --check /tmp/devops-v1.0.48-linux-x64.tar.gz`，只读核对版本、包结构和配置差异。
3. 备份数据库、安装目录、`application.properties` 和 `nginx/devops.conf`，按 `stop -> upgrade -> check -> start -> status` 完成升级。
4. 在工作区分别使用协作引擎和开发引擎新建会话，核对 Key/模型联动、首条消息发送和会话引擎标识。
5. 从两种引擎的会话菜单进入定时执行，核对计划配置与执行结果。

本版本没有新增域名、DNS、证书、Nginx 虚拟主机、公开端口或外部服务要求。现场配置和运行数据继续保留；程序回滚不会自动回滚数据库。
