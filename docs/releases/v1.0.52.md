# Agents Platform v1.0.52

发布日期：2026-09-03

`v1.0.52` 让每位用户独立维护自己的模型连接，并把双引擎对话的思考、工具轨迹、时间和配置恢复整理为一致体验。

## 本次更新

- 每位用户都可以添加和维护自己的 API Key 与模型；模型连接支持个人、全局和指定用户范围，使用范围更清晰。
- 新建会话和定时会话会保存实际选择的执行引擎、API Key 与模型，后续执行不受 Agent 默认配置切换影响。
- 协作引擎和开发引擎统一显示完整思考与工具运行轨迹，支持逐项及全局展开或收起，历史消息也保留完整过程。
- 每轮对话显示发送时间和处理时长；非当天消息包含日期，进行中时长实时更新。
- 内外层滚动在边界处自然衔接，思考区域不会挡住运行过程或阻断外层会话滚动。
- 修复刷新会话时旧本地配置触发重复保存并提示“会话设置保存失败”的问题。
- 旧 Workflow 能力正式退役，六个内置 Agent 运行环境统一更新为 `v1.0.52`。

## 安装与升级

1. 执行 `docker load -i devops-runtime-images-v1.0.52-linux-amd64.tar`，再执行 `./devops.sh images status`，确认六个运行环境可用。
2. 执行 `./devops.sh update --check` 或 `./devops.sh upgrade --check /tmp/devops-v1.0.52-linux-x64.tar.gz`，只读核对版本、包结构和配置差异。
3. 备份数据库、安装目录、`application.properties` 和 `nginx/devops.conf`，按 `stop -> upgrade -> check -> start -> status` 完成升级。
4. 分别使用模型连接所有者、被指定用户和普通用户核对连接可见范围，并验证 Agent 绑定、新建会话与定时执行。
5. 刷新一个已配置会话，确认不会出现保存失败提示；再分别用两种引擎完成一次包含思考和工具调用的对话，核对历史轨迹、折叠和处理时长。

本版本没有新增域名、DNS、证书、Nginx 虚拟主机、公开端口或外部服务要求。现场配置和运行数据继续保留；程序回滚不会自动回滚数据库。
