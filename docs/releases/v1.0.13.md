# Agents Platform v1.0.13

发布日期：2026-08-14

`v1.0.13` 集中修复 Agent 对话、Linux Docker Agent 终端和离线软件安装问题，恢复持续对话和日常开发操作的稳定性。

## 本次更新

- Agent 对话执行期间不再按秒刷新整个界面，实时内容、滚动位置和输入区保持稳定。
- 新会话执行期间保持同一会话上下文，不再因地址切换出现页面跳动或内容抖动。
- 平台会等待上一回合真正结束后再允许发送下一条消息，避免错误提示上一条消息仍在处理中。
- Linux Docker Agent 终端恢复键盘输入、交互命令和窗口尺寸同步，Windows 与远程 Agent 的原有链路保持兼容。
- Docker Agent 安装离线 JDK、Maven 和 pnpm 时直接复用服务器缓存，减少重复传输和等待。
- 修复了已知问题。

## 安装与升级

- 新客户可以使用本版本在 Linux x64 环境中连接空的 MySQL 8 数据库完成全新安装。
- `v0.0.1` 及后续正式版本都可以直接累计升级到 `v1.0.13`，无需补装中间版本；升级前可先使用只读检查命令确认环境和配置差异。
- 已安装客户先获取 `devops-runtime-images-v1.0.13-linux-amd64.tar` 并执行 `docker load -i devops-runtime-images-v1.0.13-linux-amd64.tar`，确认导入成功后再执行 `./devops.sh update`。
- 需要为 Agent 安装 JDK、Maven 或 pnpm 时，将 `devops-runtime-software-v1.0.13-linux-amd64.tar.gz` 一次解压到 `/opt/devops/devops/runtime-software-cache`；平台会自动校验并复用。
- 本版本没有新增生产配置项，也没有新增域名、DNS、Nginx、证书或端口要求。
- 升级不会自动覆盖现场 `application.properties`、Nginx 配置、项目工作区、会话、Skill、MCP、运行数据和日志。
- 程序回滚不会自动回滚数据库，升级前请备份数据库、安装目录和实际配置文件。

生产环境要求 Linux x64、Java 21+、MySQL 8 与 Docker。详细步骤请参阅官网部署指南和安装包内说明。
