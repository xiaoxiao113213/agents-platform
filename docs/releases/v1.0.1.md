# Agents Platform v1.0.1

发布日期：2026-08-08

`v1.0.1` 让团队可以更准确地分配 Agent 能力，并改善项目网站与外部服务在工作区中的访问体验。

## 本次更新

- 本地 Agent、远程 Agent 和 Skill 工作台可以分别授权，管理员可以按岗位开放需要的能力。
- 项目网站与平台使用同一访问地址，在项目之间切换时仍能保持清晰、稳定的访问路径。
- 用户配置的外部项目服务可以在对话右侧、弹层或新窗口中打开；目标网站不支持页面内打开时，平台会说明需要调整的嵌入、HTTPS、Cookie 或登录条件。
- 提问、审批和异常信息统一使用 Agent 产品语言，界面表达更加一致。
- 官方安装包补充清晰的软件许可，个人或同一法人实体可免费在自己控制的环境中使用官方未修改的二进制版本。
- 修复了已知问题。

## 安装与升级

- 新客户可以使用本版本在 Linux x64 环境中连接空的 MySQL 8 数据库完成全新安装。
- `v1.0.0` 用户可以直接升级到 `v1.0.1`，升级前可先使用安装包中的只读检查命令确认环境和配置差异。
- `v1.0.0` 是 v1 安装代际基点，`v0.x` 不支持原地升级到 `v1.x`。请使用新的安装目录和空数据库部署 v1 版本。
- 升级不会自动覆盖现场配置。正式操作前请备份数据库、安装目录和配置文件。

生产环境要求 Linux x64、Java 21+、MySQL 8 与 Docker。详细步骤请参阅官网部署指南和安装包内说明。
