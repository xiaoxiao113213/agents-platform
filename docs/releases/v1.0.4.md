# Agents Platform v1.0.4

发布日期：2026-08-10

`v1.0.4` 重点改善多人共享 Agent 的对话稳定性、模型接入和日常配置体验，同时让安装升级过程更清晰、更容易恢复。

## 本次更新

- 多人共用同一 Agent 和会话时，消息、任务进度、工具结果与最终回复会按同一顺序实时同步；同一会话会等待上一轮完成后再接受下一轮，避免内容交叉。
- 压缩上下文后的消息展示更加稳定，处理中内容不会在结束瞬间消失，也不需要刷新页面才能看到完整结果。
- 新增 DeepSeek 与 Kimi 内置模型服务。选择服务后只需填写 API Key，即可选择平台内置模型，并清楚查看将应用的模型配置；自定义模型服务仍可自由填写地址与模型。
- Grafana Agent 创建后可以重新修改 Grafana 地址、服务令牌、默认文件夹和多数据源绑定，运行中的 Agent 保存后自动应用。
- 从 Skills 平台同步大型 Office、PPT 和表格类 Skill 时，可支持更完整的资源包，同时继续校验压缩包安全性。
- 最高管理员账号与角色只对最高管理员本人可见和可操作；API Key 管理与自动化管理入口集中由最高管理员维护。
- Linux 启动器新增独立镜像查看与下载命令，下载时持续显示分层进度、等待提示和耗时；在线升级支持断点续传，并复用已下载完成的安装包。
- Agent 管理操作区、小屏布局、站点图标和登录页细节得到优化，并修复了已知问题。

## 安装与升级

- 新客户可以使用本版本在 Linux x64 环境中连接空的 MySQL 8 数据库完成全新安装。
- `v0.0.1` 及后续正式版本都可以直接累计升级到 `v1.0.4`，无需补装中间版本；升级前可先使用安装包中的只读检查命令确认环境和配置差异。
- 已安装客户可以先独立更新启动器，再使用 `./devops.sh update` 在线升级；运行环境也可以通过独立命令提前下载。
- 升级不会自动覆盖现场 `application.properties`、Nginx 配置、运行数据和日志。
- 跨较大版本升级前，请在数据库备份副本上核对业务数据，并备份数据库、安装目录和实际配置文件。
- 程序回滚不会自动回滚数据库，恢复旧程序前必须确认数据库兼容或同时恢复升级前备份。

生产环境要求 Linux x64、Java 21+、MySQL 8 与 Docker。详细步骤请参阅官网部署指南和安装包内说明。
