# Agents Platform v1.0.42

发布日期：2026-08-27

`v1.0.42` 让开发者中心的访问边界更清晰，也让运维人员可以一次性导出服务机器全部内存进程进行分析。

## 本次更新

- 开发者中心现已接入菜单和角色授权，可分别控制页面访问、开发应用管理、API Key 管理与调用审计查看。
- 没有页面权限的角色不会看到开发者中心入口；操作权限同时约束页面按钮和服务端接口。
- 运维看板新增“导出全部”，生成 Excel 时读取当前 Linux 服务机器全部进程，不受页面 Top 10 / Top 20 限制。
- 导出内容包括程序、PID、内存占用、宿主机内存占比、脱敏启动命令、Docker 容器、Agent、所属用户和采样时间。
- 无法识别 Docker、Agent 或所属用户时对应单元格保持空白，便于继续筛选和分析。

## 兼容性

- 本版本不新增域名、DNS、证书、公开端口或生产配置键。
- 现有账号、角色、Agent、项目、会话、开发应用、API Key 和审计记录保持兼容。
- 其他角色不会自动获得开发者中心权限，升级后由管理员按职责授权。

## 安装与升级

1. 执行 `docker load -i devops-runtime-images-v1.0.42-linux-amd64.tar`，再执行 `./devops.sh images status`，确认所有运行环境均可用。
2. 执行 `./devops.sh update --check` 或 `./devops.sh upgrade --check /tmp/devops-v1.0.42-linux-x64.tar.gz`，只读核对版本、包结构和现场配置差异。
3. 完成备份后按 `./devops.sh stop`、`./devops.sh upgrade /tmp/devops-v1.0.42-linux-x64.tar.gz`、`./devops.sh check`、`./devops.sh start`、`./devops.sh status` 的顺序完成升级。
4. 在角色管理中为目标角色勾选开发者中心所需权限，使用该角色确认入口和操作范围。
5. 最高管理员进入“全局看板 → 运维看板”，点击“导出全部”，确认 Excel 可以打开并包含当前服务机器进程。

升级前请备份数据库、安装目录和现场配置。现场 `application.properties` 与 `nginx/devops.conf` 应继续保留；程序回滚不会自动回滚数据库。
