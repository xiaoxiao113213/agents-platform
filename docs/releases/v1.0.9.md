# Agents Platform v1.0.9

发布日期：2026-08-11

`v1.0.9` 让 Agent 开发的不再只是静态页面：前端、Java、Node.js、Python 和前后端一体项目都可以在项目空间中稳定运行、检查并通过独立地址访问。

## 本次更新

- 每个 Agent 项目都可以按需添加项目应用能力，在当前项目中管理服务的启动、停止、重启、运行状态和访问入口。
- 项目应用使用独立子域名访问，静态网站与动态后端服务采用一致入口，项目之间相互隔离。
- 启动服务前自动检查端口占用和已有进程，重复操作不会无意启动多份服务；运行异常时提供清晰状态。
- 对话中可以直接为当前项目搜索、添加、更新或移除 Skill，同一 Agent 的不同项目可以使用不同能力组合。
- 新增覆盖 React、Spring Boot、Node.js、Python、前后端分离和一体化工程的内置 Skill，常用工程约定可以直接加入项目。
- 带数据库的工程默认采用随服务启动自动升级的数据库迁移方式，升级失败时不会错误进入可用状态。
- 安装向导和环境检查补充项目应用域名与访问配置，并修复了已知问题。

## 安装与升级

- 新客户可以使用本版本在 Linux x64 环境中连接空的 MySQL 8 数据库完成全新安装。
- `v0.0.1` 及后续正式版本都可以直接累计升级到 `v1.0.9`，无需补装中间版本；升级前可先使用只读检查命令确认环境和配置差异。
- 已安装客户可以先独立更新启动器，再使用 `./devops.sh update` 在线升级；运行环境也可以通过独立命令提前下载。
- 升级不会自动覆盖现场 `application.properties`、Nginx 配置、运行数据和日志。
- 使用项目应用独立地址前，需要把项目应用根域的通配 DNS 指向平台服务器；HTTPS 环境还需要配置对应通配证书。
- 跨较大版本升级前，请在数据库备份副本上核对业务数据，并备份数据库、安装目录和实际配置文件。
- 程序回滚不会自动回滚数据库，恢复旧程序前必须确认数据库兼容或同时恢复升级前备份。

生产环境要求 Linux x64、Java 21+、MySQL 8 与 Docker。详细步骤请参阅官网部署指南和安装包内说明。
