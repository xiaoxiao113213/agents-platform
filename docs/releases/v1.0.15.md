# Agents Platform v1.0.15

发布日期：2026-08-14

`v1.0.15` 修复项目服务在平台重启、Agent 重启或容器重建后仍显示运行中但实际无法打开的问题。

## 本次更新

- 容器重建后即使本地服务状态记录丢失，也会使用平台保存的完整服务配置重新建立运行状态。
- 打开项目服务前会确认真实运行状态，过期的进程和端口信息不再直接用于访问。
- 项目服务首访和后台巡检使用同一恢复流程，避免重复启动以及长期停留在错误状态。
- 项目服务响应超时会被正确识别为服务故障，不再误报为登录或权限失效。
- 恢复过程保留失败次数和等待保护，项目自身配置错误时不会形成无限重启。
- 平台、Agent 或项目服务暂时离线时会给出明确状态，恢复连接后继续自动校正。
- 修复了已知问题。

## 安装与升级

- 新客户可以使用本版本在 Linux x64 环境中连接空的 MySQL 8 数据库完成全新安装。
- `v0.0.1` 及后续正式版本都可以直接累计升级到 `v1.0.15`，无需补装中间版本；升级前可先使用只读检查命令确认环境和配置差异。
- 已安装客户先获取 `devops-runtime-images-v1.0.15-linux-amd64.tar` 并执行 `docker load -i devops-runtime-images-v1.0.15-linux-amd64.tar`，确认导入成功后再执行 `./devops.sh update`。
- 需要为 Agent 安装 JDK、Maven 或 pnpm 时，将 `devops-runtime-software-v1.0.15-linux-amd64.tar.gz` 一次解压到 `/opt/devops/devops/runtime-software-cache`；平台会自动校验并复用。
- 本版本没有新增生产配置项，也没有新增域名、DNS、Nginx、证书或端口要求。
- 升级不会自动覆盖现场 `application.properties`、Nginx 配置、项目工作区、会话、Skill、MCP、运行数据和日志。
- 程序回滚不会自动回滚数据库，升级前请备份数据库、安装目录和实际配置文件。

生产环境要求 Linux x64、Java 21+、MySQL 8 与 Docker。详细步骤请参阅官网部署指南和安装包内说明。
