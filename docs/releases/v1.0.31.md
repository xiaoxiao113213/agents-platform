# Agents Platform v1.0.31

## 版本概览

`v1.0.31` 让平台的登录、主题、Agent 项目和对话体验形成完整闭环。所有业务入口统一在登录后使用；管理员可以维护品牌与场景主题并按角色分配，多个角色对应不同主题时，成员可以主动切换并保留偏好。对话、最近项目、Skill、MCP、应用和 Agent 配额也完成了一轮面向日常使用的可靠性与信息架构优化。

## 主要更新

- 平台首页、能力广场、Agent、项目、会话、Skill、MCP、Issue 与系统管理统一要求登录。未登录打开受保护地址时会进入登录页，成功登录后继续打开原目标。
- 新增主题管理，支持维护 Logo、页面背景、内容容器、文本、按钮与状态颜色。内置默认、律所、工业制造、编程研发等 8 套可编辑主题，可按角色绑定和发布。
- 多角色成员可以从账号菜单切换对应主题；选择会在刷新后保持，不同场景主题在页面背景、容器和强调色上具有清晰差异。
- 主题编辑页新增分组配色、Logo 配置、发布设置、备注与实时预览；classic 和 project 两套登录页同步增强品牌展示、层次和响应式体验。
- 会话不再显示“设置标签”和配置齿轮，输入区移除固定建议；思考内容在实时输出与历史恢复之间保持稳定，不再反复拆分和合并。
- 用户离开正在执行的会话后，后台任务完成会收到明确提醒，并可通过“查看结果”直接回到对应 Agent、项目和会话。
- 最近项目支持搜索并显示所属 Agent，点击后恢复真实工作区；主导航、对话列表和悬浮工具栏的折叠状态会跨项目、跨刷新保持。
- `skill-creator` 与 `find-skills` 成为所有 Agent 的平台能力，文件产物收集和远程 Agent 提交更加可靠。
- Agent 达到创建数量上限后不再显示创建入口，平台仍会在提交时进行最终配额校验，避免旧页面或重复请求绕过限制。
- 用户界面统一使用“应用”描述项目中运行的服务；project 的 MCP 页面改为直接展示 MCP 实例、Server、所属项目、Agent 与同步状态。
- 最高权限账号改由受控系统属性识别，不再依赖固定账号编号；该属性不出现在普通用户与角色维护页面中。
- Linux 包继续同时提供 classic 与 project 两套 Web，历史项目、会话、文件、主题选择和现场配置在累计升级时保留。
- JDK、Maven、pnpm 软件内容没有变化，继续复用 `v1.0.15` 软件离线包和服务器缓存。
- 修复了已知问题。

## 安装与升级

### 前置条件

- 继续使用 Linux x64、Java 21+、MySQL 8、Docker 和独立 Nginx；本版本不新增配置键、DNS、证书、公开端口或外部服务要求。
- 项目应用继续沿用既有项目根域、通配 DNS 和 Nginx 项目应用虚拟主机；已完成配置的环境无需重复修改。
- 升级前备份数据库、安装目录、`application.properties` 和 `nginx/devops.conf`。

### 升级步骤

1. 执行 `docker load -i devops-runtime-images-v1.0.31-linux-amd64.tar` 导入本版本 6 个运行环境，再执行 `./devops.sh images status`。
2. 必要时先运行 `curl -fsSL https://mmmqaz.cn/releases/update-launcher.sh | bash`，并确认 `./devops.sh launcher-version` 不低于 `15`。
3. 执行 `./devops.sh upgrade --check /tmp/devops-v1.0.31-linux-x64.tar.gz`，确认版本、配置差异和包结构。
4. 执行 `./devops.sh stop`、`./devops.sh upgrade /tmp/devops-v1.0.31-linux-x64.tar.gz`、`./devops.sh check`、`./devops.sh start` 和 `./devops.sh status`。
5. 登录后在账号菜单切换一个有权使用的角色主题，刷新页面确认偏好保持；进入主题管理确认内置主题可查看和编辑。
6. 打开最近项目、一个历史会话、Skill 和 MCP 页面，确认所属 Agent、会话内容、平台 Skill 与 MCP 实例正常显示。
7. 在另一个会话启动短任务并切换离开，任务结束后确认出现完成提醒且“查看结果”能够返回目标会话。
8. 达到 Agent 数量上限的账号不应看到创建入口；未达到上限的账号仍可按原流程创建。

### 全新安装

- 默认安装经典界面：`./devops.sh install --web classic`。
- 安装项目式界面：`./devops.sh install --web project`。
- 安装完成后仍可使用 `./devops.sh web use classic|project` 切换，不需要迁移数据或修改后端配置。

同版本与降级仍会被拒绝。程序回滚不会自动回滚数据库，升级前必须保留可恢复备份；升级和回滚都不会覆盖现场 `application.properties`、`nginx/devops.conf`、项目工作区、文件与运行数据。
