# Agents Platform v1.0.25

## 版本概览

`v1.0.25` 优化 Agent 对话中长篇 Markdown 的阅读密度，让正文、标题和列表在保持结构清楚的同时展示更多有效内容。

## 主要更新

- Agent 对话正文使用更紧凑的行高和段落间距，长篇中文回复可以连续阅读更多内容。
- 标题、普通列表、嵌套列表和相邻列表项分别控制间距，层级仍然清楚，不再出现大片空白。
- Markdown 源码中的结构换行不再被重复放大为额外空白行。
- 代码块、引用、表格、公式和图表继续保留独立间距，技术内容不会因正文压缩而拥挤。
- 调整只作用于 Agent 消息正文，不影响工具调用、审批卡片、输入区和不同消息之间的边界。
- JDK、Maven、pnpm 软件内容没有变化，继续复用 `v1.0.15` 软件离线包和服务器缓存。
- 修复了已知问题。

## 升级说明

1. 升级前备份数据库、安装目录、`application.properties` 和 `nginx/devops.conf`。
2. 执行 `docker load -i devops-runtime-images-v1.0.25-linux-amd64.tar` 导入本版本运行环境。
3. 执行 `./devops.sh upgrade --check /tmp/devops-v1.0.25-linux-x64.tar.gz`，确认版本、配置差异和包结构。
4. 完成累计升级后运行 `./devops.sh check`，启动服务并等待 Agent 重新连接。
5. 打开一个包含多级标题、连续段落、普通列表、嵌套列表、代码块和表格的已有长会话，确认排版紧凑且内容边界清楚。
6. 本版本没有新增平台 Nginx 参数，升级器会保留现场配置；执行 `nginx -t` 后再重载。
7. 需要离线安装 JDK、Maven 或 pnpm 时继续使用 `devops-runtime-software-v1.0.15-linux-amd64.tar.gz`。

同版本与降级仍会被拒绝。程序回滚不会自动回滚数据库，升级前必须保留可恢复备份。
