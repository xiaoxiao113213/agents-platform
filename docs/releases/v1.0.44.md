# Agents Platform v1.0.44

发布日期：2026-08-28

`v1.0.44` 让 Agent 对话历史更完整、更易读。主对话聚焦用户消息和模型正式回答，历史由平台稳定保存，进行中的工具状态仍会在需要时明确显示。

## 本次更新

- 历史主对话隐藏已完成的思考、工具调用和工具结果，长对话浏览更紧凑。
- 用户输入和模型正式回答由平台持久保存；上下文压缩后仍可继续查看更早对话。
- 升级后会自动分批补齐已有会话的正文历史，重复扫描不会产生重复消息。
- 对话执行期间展示最后一个工具调用；工具完成后仍保持可见，直到模型正式正文开始输出再自动收起。
- 切换到其他会话再返回时，进行中的草稿、最后工具和停止操作会自动恢复。
- “加载更早的消息”直接从平台历史中批量读取，并尽量补足多轮可见问答，远程 Agent 下也不再反复跨页读取运行轨迹。
- 完整原始轨迹继续保留在“运行详情”中，排障和审计能力不受影响。
- Agent 全部项目与指定项目分享继续覆盖授权项目内的对话、文件、Skill、MCP、Workflow、应用、项目服务和计划任务。
- 具备创建权限的共享成员新建项目后，项目会自动进入其授权范围。

## 兼容性

- 本版本不新增域名、DNS、证书、公开端口或生产配置键。
- 现有账号、角色、Agent、项目、会话、分享关系、Issue 协作空间、开发应用和审计记录保持兼容。
- 运行详情仍可按原始记录分页查看，不会因为主对话精简而丢失诊断信息。
- 对话窗口与运行详情采用独立数据来源：正文历史稳定保留，实时思考和工具轨迹仍按运行时实际状态展示。
- 默认 Agent 的保护规则、Agent 全局配置边界和终端独立授权保持不变。

## 安装与升级

1. 执行 `docker load -i devops-runtime-images-v1.0.44-linux-amd64.tar`，再执行 `./devops.sh images status`，确认所有运行环境均可用。
2. 执行 `./devops.sh update --check` 或 `./devops.sh upgrade --check /tmp/devops-v1.0.44-linux-x64.tar.gz`，只读核对版本、包结构和现场配置差异。
3. 完成备份后按 `./devops.sh stop`、`./devops.sh upgrade /tmp/devops-v1.0.44-linux-x64.tar.gz`、`./devops.sh check`、`./devops.sh start`、`./devops.sh status` 的顺序完成升级。
4. 打开一段经过上下文压缩或包含多轮工具调用的长历史，点击一次“加载更早的消息”，确认可以补入多轮用户消息与模型正文。
5. 新发起一次包含工具调用的对话，切换到其他会话后再返回，确认最后一个工具和停止操作可以恢复；正文出现后临时工具状态自动收起。

升级前请备份数据库、安装目录和现场配置。现场 `application.properties` 与 `nginx/devops.conf` 应继续保留；程序回滚不会自动回滚数据库。
