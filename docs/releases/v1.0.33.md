# Agents Platform v1.0.33

## 版本概览

`v1.0.33` 优化 Project 首页的品牌展示。自定义 Logo 现在按图片自身尺寸和原始宽高比呈现，横向 Logo 不再被压进固定方框，小尺寸 Logo 也不会被无谓放大。

本版本完整继承 `v1.0.32` 的项目协作、Agent 共享、大型工作区浏览、角色多主题、模型切换和项目应用能力，不改变现有业务数据与操作方式。

## 主要更新

- Project 首页 Logo 按固有尺寸和原始比例展示，适配横向、纵向和小尺寸品牌标识。
- 超大 Logo 在响应式边界内等比缩小，不会遮挡标题或撑开项目创建区域。
- 登录页、侧边栏和主题预览继续使用稳定的固定槽位，不受首页改动影响。
- 本版本不新增域名、DNS、Nginx、证书、公开端口、生产配置键或外部服务要求。
- 修复了已知问题。

## 安装与升级

### 前置条件

- 继续使用 Linux x64、Java 21+、MySQL 8、Docker 和独立 Nginx。
- 升级前备份数据库、安装目录、`application.properties` 和 `nginx/devops.conf`。
- 确认磁盘空间足够保存并导入六个运行环境；运行环境包和主程序包必须同为 `v1.0.33`。

### 升级步骤

1. 执行 `docker load -i devops-runtime-images-v1.0.33-linux-amd64.tar`，再执行 `./devops.sh images status`，确认六个运行环境均可用。
2. 必要时先运行 `curl -fsSL https://mmmqaz.cn/releases/update-launcher.sh | bash`，并确认 `./devops.sh launcher-version` 不低于 `15`。
3. 执行 `./devops.sh upgrade --check /tmp/devops-v1.0.33-linux-x64.tar.gz`，确认版本、包结构和现场配置差异。
4. 执行 `./devops.sh stop`、`./devops.sh upgrade /tmp/devops-v1.0.33-linux-x64.tar.gz`、`./devops.sh check`、`./devops.sh start` 和 `./devops.sh status`。
5. 不要覆盖现场 `application.properties` 或 `nginx/devops.conf`。

### 产品内验收

1. 登录 Project 界面并进入首页，确认当前主题 Logo 保持原始比例，没有被压进正方形。
2. 分别选择横向 Logo 与小尺寸 Logo 的主题，确认横向 Logo 有足够展示宽度，小 Logo 没有被放大失真。
3. 打开项目列表、一个历史会话和系统管理页面，确认 `v1.0.32` 的既有功能与数据保持。

### 常见问题

- Logo 仍显示旧样式：先强制刷新浏览器并确认 Nginx 静态目录已切换到新包的 `web/current`。
- Logo 显示尺寸受限：超大图片会按比例缩小以保护首页布局；建议上传已裁去透明留白的品牌图片。
- 升级预检提示配置差异：保留现场文件，以包内 `.example` 为参考逐项合并，不要直接覆盖域名、证书、数据库连接和本地存储目录。

### 全新安装

- 默认安装经典界面：`./devops.sh install --web classic`。
- 安装项目式界面：`./devops.sh install --web project`。
- 安装完成后可使用 `./devops.sh web use classic|project` 切换，两套界面共用账号、权限、Agent、项目和会话数据。

同版本与降级仍会被拒绝。程序回滚不会自动回滚数据库，升级前必须保留可恢复备份；升级和回滚都不会覆盖现场配置、项目工作区、文件与运行数据。
