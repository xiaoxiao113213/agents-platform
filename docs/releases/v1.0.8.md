# Agents Platform v1.0.8

发布日期：2026-08-11

`v1.0.8` 让大型会话重新进入更快，任务状态和最终消息更稳定，产物展示也更加可靠。

## 本次更新

- 大型会话优先加载最近消息，需要时可继续查看更早内容，重新进入对话不再因一次加载全部历史而长时间卡顿。
- 多人共用 Agent 和会话时，正在生成的消息、最终回复与会话状态保持一致，页面刷新后也能恢复正确结果。
- 已结束的任务不再错误显示为运行中，任务进度、标题和长计划在对话区内保持紧凑稳定。
- 长计划先展示摘要，展开后可完整阅读，避免超长内容挤压输入区或造成页面频繁跳动。
- 会话产物打开更快，手工刷新仍可重新校准；无效或空白产物不再占据列表。
- 减少重复的后台请求，并修复了已知问题。

## 安装与升级

- 新客户可以使用本版本在 Linux x64 环境中连接空的 MySQL 8 数据库完成全新安装。
- `v0.0.1` 及后续正式版本都可以直接累计升级到 `v1.0.8`，无需补装中间版本；升级前可先使用只读检查命令确认环境和配置差异。
- 已安装客户可以先独立更新启动器，再使用 `./devops.sh update` 在线升级；运行环境也可以通过独立命令提前下载。
- 升级不会自动覆盖现场 `application.properties`、Nginx 配置、运行数据和日志。
- 跨较大版本升级前，请在数据库备份副本上核对业务数据，并备份数据库、安装目录和实际配置文件。
- 程序回滚不会自动回滚数据库，恢复旧程序前必须确认数据库兼容或同时恢复升级前备份。

生产环境要求 Linux x64、Java 21+、MySQL 8 与 Docker。详细步骤请参阅官网部署指南和安装包内说明。
