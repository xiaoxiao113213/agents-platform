# Agents Platform v1.0.6

发布日期：2026-08-10

`v1.0.6` 带来更细致的模型连接共享、更清晰的用量分析，以及更稳定的多人共享对话和长任务执行体验。

## 本次更新

- 模型连接可以选择全局共享或仅授权给指定成员，在团队复用和使用边界之间灵活切换。
- 新增模型用量分析，可按时间、连接、成员和模型筛选，并查看请求次数及输入、输出和总 Token 用量。
- 删除正在使用的模型连接前会展示关联内容，并可先批量替换到其他连接，减少 Agent 配置中断。
- 多人共用一个 Agent 和会话时，每轮消息、任务过程与最终结果会更稳定地保持一致。
- 长任务会更早整理上下文并继续执行，降低达到模型上下文上限后意外中断的概率。
- Agent 创建者信息显示更准确，历史数据库升级兼容性得到改善，并修复了已知问题。

## 安装与升级

- 新客户可以使用本版本在 Linux x64 环境中连接空的 MySQL 8 数据库完成全新安装。
- `v0.0.1` 及后续正式版本都可以直接累计升级到 `v1.0.6`，无需补装中间版本；升级前可先使用只读检查命令确认环境和配置差异。
- 已安装客户可以先独立更新启动器，再使用 `./devops.sh update` 在线升级；运行环境也可以通过独立命令提前下载。
- 升级不会自动覆盖现场 `application.properties`、Nginx 配置、运行数据和日志。
- 跨较大版本升级前，请在数据库备份副本上核对业务数据，并备份数据库、安装目录和实际配置文件。
- 程序回滚不会自动回滚数据库，恢复旧程序前必须确认数据库兼容或同时恢复升级前备份。

生产环境要求 Linux x64、Java 21+、MySQL 8 与 Docker。详细步骤请参阅官网部署指南和安装包内说明。
