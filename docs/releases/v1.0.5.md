# Agents Platform v1.0.5

发布日期：2026-08-10

`v1.0.5` 让团队能够更方便地复用模型连接并配置远程 Agent，同时改善累计升级后的运行环境整理体验。

## 本次更新

- 已启用的模型连接可以在团队 Agent 中共享选择。成员创建或配置 Agent 时无需重复录入已有连接，对话中仍可按会话切换可用模型。
- 创建远程 Agent 时可以一次绑定多个模型连接，并指定新会话默认使用的连接和模型。
- 模型连接的新增、编辑、停用和删除仍由具备管理权限的成员负责，Agent 的日常使用不会被连接维护权限阻断。
- Linux 累计升级成功后会自动整理上一版本的运行环境；没有被任何 Agent 使用的旧版本内容会被清理，仍被运行中或已停止 Agent 使用的内容会保留。
- 安装包、启动器帮助和官网指南统一说明当前累计升级范围，并修复了已知问题。

## 安装与升级

- 新客户可以使用本版本在 Linux x64 环境中连接空的 MySQL 8 数据库完成全新安装。
- `v0.0.1` 及后续正式版本都可以直接累计升级到 `v1.0.5`，无需补装中间版本；升级前可先使用只读检查命令确认环境和配置差异。
- 已安装客户可以先独立更新启动器，再使用 `./devops.sh update` 在线升级；运行环境也可以通过独立命令提前下载。
- 升级不会自动覆盖现场 `application.properties`、Nginx 配置、运行数据和日志。
- 跨较大版本升级前，请在数据库备份副本上核对业务数据，并备份数据库、安装目录和实际配置文件。
- 程序回滚不会自动回滚数据库，恢复旧程序前必须确认数据库兼容或同时恢复升级前备份。

生产环境要求 Linux x64、Java 21+、MySQL 8 与 Docker。详细步骤请参阅官网部署指南和安装包内说明。
