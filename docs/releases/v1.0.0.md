# v1.0.0 Agent 工作平台全新版本

发布日期：2026-08-08

## 本次更新

- Agent 成为平台主入口。团队成员可以在授权范围内创建、使用和共享同一份 Agent，共同查看会话、项目文件、任务和产物。
- 内置通用、数据库、网站、Issue、Grafana、PPT 和视频七类 Agent，可覆盖研发、数据、运营内容和自动化交付场景。
- 数据库 Agent 在同一工作区内完成数据库问答、结构设计和 SQL 操作，重要变更会要求明确确认。
- Issue 成为 Agent 项目的内置协作能力，一个项目目录绑定一个 Issue 项目，并支持评论沟通、需求澄清、处理状态和定时跟进。
- Skill 可通过 ZIP 上传、同步和公开到能力广场，安装后直接提供给 Agent 使用。
- 定时任务支持一次、周期和间隔执行，也可在没有待处理 Issue 时跳过对话，减少无效运行。
- 项目服务支持独立页面、弹窗和对话区并排打开，并改善登录态保持与窄屏布局。
- 对话支持多个 API Key、模型切换、上下文压缩、会话重命名和完整用量查看。
- 支持 Windows 与 Linux 远程 Agent，并修复了已知问题。

## 安装说明

`v1.0.0` 是全新的安装代际，只支持在 Linux 服务器的新目录中连接空 MySQL 8 数据库完成首次安装，不支持从 `v0.x` 原地升级。后续 `v1.x` 补丁版本将继续提供同代升级能力。

生产环境请使用 GitHub Release 提供的 `devops-v1.0.0-linux-x64.tar.gz` 正式包，并按官网部署指南完成环境检查和安装。
