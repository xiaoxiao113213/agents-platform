# Agents Platform v1.0.47

发布日期：2026-08-31

`v1.0.47` 完成双运行引擎与开发者 Agent Console 的产品化收口。团队既可以在主平台工作区中使用完整对话能力，也可以通过 Java SDK 和 Spring Boot + React 案例构建行为一致的独立 Agent 管理台。

## 本次更新

- 协作引擎与开发引擎都支持项目规则、Skill、MCP、产物、文件、终端、运行详情和长任务执行。
- 会话会保存执行引擎、模型与模式；切换会话、刷新页面或服务重启后，历史正文和进行中状态可以继续恢复。
- 主对话聚焦用户输入和模型正式回答；完整思考和工具过程保留在运行详情中。
- 开发者 Agent Console 复制主平台工作区，覆盖项目、会话、历史消息、输入区、附件、审批、排队消息、产物、应用、Skill、文件和协作空间。
- 项目 Skill 支持搜索、分类、分页、添加、移除、版本状态和贡献共享能力。
- Java SDK 与 Console BFF 增强会话状态、任务控制、审批和项目能力接口，所有操作继续受应用账号现有角色与分享范围约束。
- 修复双引擎切换、规划模式、长任务、历史消息、流式正文、运行轨迹、产物发现和远程环境变量等已知问题。
- 六个内置 Agent 运行环境统一更新为 `v1.0.47`。

## 安装与升级

1. 执行 `docker load -i devops-runtime-images-v1.0.47-linux-amd64.tar`，再执行 `./devops.sh images status`，确认六个运行环境可用。
2. 执行 `./devops.sh update --check` 或 `./devops.sh upgrade --check /tmp/devops-v1.0.47-linux-x64.tar.gz`，只读核对版本、包结构和配置差异。
3. 备份数据库、安装目录、`application.properties` 和 `nginx/devops.conf`，按 `stop -> upgrade -> check -> start -> status` 完成升级。
4. 登录平台打开一段已有长会话，核对用户输入、模型正文与运行详情；再分别检查两个运行引擎的模型、模式和项目能力。
5. 使用开发者应用账号进入 Agent Console 案例，核对同一 Agent、项目和历史会话的页面与能力范围。

本版本没有新增域名、DNS、证书、Nginx 虚拟主机、公开端口或外部服务要求。现场配置和运行数据继续保留；程序回滚不会自动回滚数据库。
