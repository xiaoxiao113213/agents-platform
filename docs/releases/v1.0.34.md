# Agents Platform v1.0.34

## 版本概览

`v1.0.34` 完善协作空间、Agent 扩展能力和长任务运行边界。事项从提交、AI 接管、用户澄清到完成关闭形成可追踪闭环；项目资料、MCP 与 Skill 可以在 Agent 项目中持续同步和直接生效。

本版本同时增加 Agent 归属筛选和主 Agent 标识，扩展自定义 MCP 管理，并提供面向普通用户的独立版本历史页面。

## 主要更新

- Issue 产品概念统一为“协作空间”，事项状态、资料、Agent Skill 与 MCP 使用一致的用户语言。
- AI 完成事项后直接关闭并保留完整操作记录，不再要求额外人工审核；用户补充澄清后会自动重新进入 AI 队列。
- 协作空间资料支持多级文件夹和指定目录写入，新建或修改后立即生效，长文档可完整滚动阅读。
- 协作空间 MCP 与处理 Skill 支持版本识别、自动同步和手动重复同步，Agent 在线后持续保持最新能力。
- MCP 管理新增自定义 stdio 与 HTTP 实例，支持完整新增、编辑、启停、同步和删除，密钥不会明文回显。
- Agent 列表可快速筛选“我的 Agent”和“他人共享”，个人主 Agent 使用明确标签标识。
- 新增独立版本历史与详情页面，以非研发语言查看每次迭代的功能、升级和验收说明。
- 优化后台子 Agent 的等待策略，重复长轮询会自动限时或降级，减少长任务停滞和无效等待。
- 修复本地开发模式下前端文件访问范围配置导致的页面无法打开问题，并修复了其他已知问题。

## 安装与升级

### 前置条件

- 继续使用 Linux x64、Java 21+、MySQL 8、Docker 和独立 Nginx。
- 升级前备份数据库、安装目录、`application.properties` 和 `nginx/devops.conf`。
- 确认磁盘空间足够保存并导入六个运行环境；运行环境包和主程序包必须同为 `v1.0.34`。
- 本版本没有新增域名、DNS、证书、公开端口或生产配置键。

### 升级步骤

1. 执行 `docker load -i devops-runtime-images-v1.0.34-linux-amd64.tar`，再执行 `./devops.sh images status`，确认六个运行环境均可用。
2. 必要时先运行 `curl -fsSL https://mmmqaz.cn/releases/update-launcher.sh | bash`，并确认 `./devops.sh launcher-version` 不低于 `15`。
3. 执行 `./devops.sh upgrade --check /tmp/devops-v1.0.34-linux-x64.tar.gz`，确认版本、包结构和现场配置差异。
4. 执行 `./devops.sh stop`、`./devops.sh upgrade /tmp/devops-v1.0.34-linux-x64.tar.gz`、`./devops.sh check`、`./devops.sh start` 和 `./devops.sh status`。
5. 不要覆盖现场 `application.properties` 或 `nginx/devops.conf`。

### 产品内验收

1. 登录平台，打开协作空间，创建事项并提交给 AI，确认处理、澄清和关闭记录完整显示。
2. 在资料区创建二级文件夹和文档，确认保存后可以立即读取，并能滚动查看到底部。
3. 为一个 Agent 项目绑定协作空间能力，确认 MCP 与 Skill 显示同步成功；再次同步应保持成功。
4. 在 MCP 管理中新增一个测试用自定义实例，完成编辑、同步和删除，确认项目配置随操作更新。
5. 在 Agent 列表切换“我的”和“他人共享”，确认个人主 Agent 标签清晰可见。
6. 打开版本历史页面，确认 `v1.0.34` 与历史版本说明均可独立查看。

### 常见问题

- Agent 能力显示待同步：确认 Agent 在线，等待自动同步或在能力管理中手动执行同步。
- 自定义 MCP 同步失败：检查启动命令、参数或 HTTP 地址，并确认目标 Agent 能访问对应程序或服务。
- 资料目录无法删除：文件夹必须为空；先移动或删除其中资料，再删除文件夹。
- 页面仍显示旧术语或旧入口：强制刷新浏览器并确认 Nginx 静态目录已切换到新包的 `web/current`。
- 升级预检提示配置差异：保留现场文件，以包内 `.example` 为参考逐项合并，不要直接覆盖域名、证书、数据库连接和本地存储目录。

### 全新安装

- 默认安装经典界面：`./devops.sh install --web classic`。
- 安装项目式界面：`./devops.sh install --web project`。
- 安装完成后可使用 `./devops.sh web use classic|project` 切换，两套界面共用账号、权限、Agent、项目、协作空间和会话数据。

同版本与降级仍会被拒绝。程序回滚不会自动回滚数据库，升级前必须保留可恢复备份；升级和回滚都不会覆盖现场配置、项目工作区、文件与运行数据。
