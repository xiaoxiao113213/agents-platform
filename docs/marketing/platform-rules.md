# 平台发布规则

| 平台 | 内容重点 | 建议频率 | 发布要求 |
| --- | --- | --- | --- |
| 微信公众号 | 完整案例、版本说明、部署教程 | 每周 1 篇 | 标题克制，文末给出官网和许可边界 |
| 知乎 | 围绕真实问题给出完整回答 | 每周 1 篇 | 先回答问题，再介绍产品；避免自问自答式硬广 |
| CSDN / 掘金 / SegmentFault / 51CTO / 开源中国 | 架构、安装、排障、工程实践 | 每周 1 至 2 篇 | 提供可复用方法和命令，不用同文批量转载 |
| 小红书 | 场景、过程、截图和结果 | 每周 2 篇 | 竖版图卡优先，正文短，避免夸大收益 |
| B站 | 3 至 10 分钟功能演示和教程 | 每两周 1 条 | 展示真实界面和完整结果，简介附事实链接 |
| 视频号 / 抖音 | 30 至 90 秒单一功能片段 | 每周 1 至 2 条 | 一个视频只讲一个结果，字幕必须可读 |
| 微博 / 头条号 / 百家号 | 版本快讯和案例摘要 | 随版本和重点内容发布 | 使用平台改写版，不直接复制长文开头 |
| GitHub / Gitee | Release、安装说明、问题反馈 | 随正式版本更新 | 不把专有软件描述为开源项目 |
| V2EX / NodeSeek 等社区 | 实践复盘、产品讨论、问题求证 | 有真实主题时发布 | 遵守版规，不自动群发，不伪装普通用户评价 |

## 通用检查

发布前逐项确认：

- 版本号、功能、下载链接和升级范围与客户版版本说明一致。
- 标题没有绝对化承诺、虚构数据或未经授权的客户背书。
- 图片没有账号、密钥、内部地址、客户数据或未公开功能。
- 文中说明产品是专有软件，不是开源软件；免费授权仅限自然人的个人非商业使用，公司、组织或商业用途需书面授权。
- 链接使用对应平台来源参数，发布后能够正常打开。
- 平台未提示营销、转载、版权或账号资质风险。

遇到验证码、账号申诉、实名、平台协议确认或疑似违规提示时停止自动操作，交由账号所有者处理。
