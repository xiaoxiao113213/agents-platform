# Agents Platform 公开品牌口径

## 核心表达

- 产品名：Agents Platform
- 一句话定位：面向企业团队的 Agent 工作平台，让 Agent 进入项目、连接获准使用的数据与业务系统，并交付真实结果。
- 核心主张：让 Agent 进入项目，完成真实工作。

## 可以公开说明的能力

- 每个 Agent 拥有项目目录、会话、文件、任务和交付物，而不是只有聊天框。
- 平台提供通用、数据库、网站开发、Issue 处理、Grafana、PPT 和视频七类内置 Agent。
- Agent 可以在授权范围内连接代码、数据库、Issue、流水线、质量、基础设施和可观测系统。
- 平台支持团队成员创建、共享和持续使用 Agent，并通过权限控制能力范围。
- 产品由客户部署在自己的 Linux 环境中，项目、会话、文件和业务数据由部署方管理。
- 官方未修改的二进制安装包仅供自然人个人非商业使用。

## 必须同时说明的边界

- Agents Platform 是专有软件，不是开源软件。
- 任何公司、企业、法人、其他组织或商业用途，包括内部试用、评估、研发、测试和生产部署，均需事先取得书面授权。
- 免费授权不包含核心源码、再分发、OEM、SaaS 转售或面向第三方的托管服务。
- Agent 的结果需要按业务风险接受人工复核，生产变更、数据写入和对外发布应有确认流程。
- 当前生产环境要求和版本升级范围以官网最新正式版本说明为准。

## 禁止使用的表达

- “完全自动”“零风险”“百分之百正确”“替代所有员工”等无法验证的绝对承诺。
- “开源平台”“免费商用源码”等与许可冲突的表述。
- 未经书面许可使用客户名称、Logo、内部数据、对话截图或效果背书。
- 把规划中、开发中或尚未完成正式发布的能力写成已经可用。
- 对比竞品时捏造价格、能力、安全性或市场份额。

## 文案风格

从真实工作和具体交付出发，先说明问题，再展示 Agent 如何获得上下文、执行步骤并留下结果。少使用“赋能、颠覆、全栈智能化”等空泛词，避免把平台描述成另一个聊天机器人。
