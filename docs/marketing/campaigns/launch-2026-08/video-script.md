## 60 秒短视频版

很多 AI 会回答问题，但它不在项目现场。

代码在仓库，任务在 Issue，数据在数据库，运行状态在 Docker 和 Kubernetes，最后的交付物又散落在各种文件里。

Agents Platform 把项目、会话、文件、任务和交付物放到同一份 Agent 工作空间。它可以接管 Issue、处理跨端故障、生成 SQL 和 Grafana 大盘，也可以交付网站、PPT 和视频。

平台部署在自己的 Linux 环境中，数据由部署方管理，高风险操作保留人工确认。

当前正式版本 v1.0.5。官网 mmmqaz.cn。
